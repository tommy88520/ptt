# 使用條款與注意事項

最後更新：2026-07-30

本文件不是正式法律文件，是這個個人專案（以下稱「本服務」）的使用說明與免責聲明。如果之後要正式營運（例如開放付費），建議請律師審閱後再正式採用。

## 1. 這是什麼服務

本服務會定期擷取 PTT MacShop 看板的公開文章（標題、作者、發文時間、內文、推文數），提供搜尋功能，並讓使用者透過 Discord 帳號登入後訂閱關鍵字，符合的新文章會以 Discord 私訊通知。

本服務是個人開發、非官方的第三方工具，**與 PTT（批踢踢實業坊）、國立台灣大學、Discord Inc. 均無任何關係，未獲得上述單位授權或背書**。

## 2. 資料來源與著作權

- 本服務顯示的文章內容擷取自 PTT MacShop 看板的公開頁面，著作權屬於原發文者與 PTT 平台所有,本服務僅提供搜尋/通知的索引功能,不會宣稱擁有這些內容的著作權
- 本服務只保留文章的公開資訊(標題/作者/內文/連結等),提供的搜尋結果一律附上原文連結,鼓勵使用者回到 PTT 原站閱讀完整討論與推文
- 若原發文者或 PTT 官方要求下架特定內容,會配合處理

## 3. 帳號與資料蒐集

- 登入方式為 **Discord OAuth2**,只會取得 Discord 提供的公開識別資訊(使用者 ID、使用者名稱),**不會取得你的 Discord 密碼,也不會讀取你的訊息或伺服器內容**
- 會儲存的個人相關資料只有:你的 Discord 使用者 ID、你設定的訂閱關鍵字、訂閱建立時間
- 不會蒐集 email、真實姓名、付款資訊(除非未來加入付費功能,屆時會另外說明)
- 不會把你的 Discord ID 或訂閱關鍵字提供給第三方或用於本服務以外的用途

## 4. 通知功能與使用限制

- 符合訂閱關鍵字的新文章,會透過 Discord 私訊(DM)通知,通知內容僅包含文章標題與連結
- 為避免濫用與控制成本,**非本服務擁有者的帳號,每日可收到的通知數量上限為 20 篇**,超過上限的通知會延後或不發送,不影響你在網頁/Discord 上查詢文章
- 保留視情況調整每日上限、新增付費解鎖更高額度等功能的權利
